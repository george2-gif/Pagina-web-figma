# Sanidad con Cristo

Sitio web estático sobre acompañamiento psicológico y espiritual.

## Estructura

- `index.html`: página principal y buscador de tratamientos.
- `html/`: páginas internas del sitio.
- `css/`: estilos separados por página.
- `javascript/vistas.js`: menú, buscadores y tarjetas de la página principal.
- `assets/`: imágenes e iconos locales.

## Ejecución

Abre `index.html` en un navegador o utiliza una extensión de servidor local para probar los enlaces entre páginas.
